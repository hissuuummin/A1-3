# 📋 서비스 기획서: 트립스파크 (TripSpark)

---

## 1. 서비스 개요 (Overview)

| 항목 | 내용 |
| :--- | :--- |
| **서비스명** | **트립스파크 (TripSpark)** |
| **슬로건** | "단 30초 만에 완성하는 나만의 맞춤형 여행 코스 & 경비 플래너" |
| **카테고리** | AI 기반 여행 큐레이션 및 스마트 라이프스타일 웹 서비스 |
| **배포 플랫폼**| Vercel (Front: Static SPA / Back: Vercel Serverless Functions - Python) |

### 1.1 기획 배경 및 목적
- **배경**: 여행 계획을 수립할 때 블로그, SNS, 지도 앱을 수없이 오가며 동선을 짜고 예산을 계산하는 과정에서 수많은 사용자들이 심한 피로감을 느낍니다. 특히 동행자의 성향(연인, 친구, 가족)이나 여행 스타일(휴양, 맛집, 뚜벅이)에 맞춘 일정을 직접 조합하는 데 많은 시간이 소요됩니다.
- **목적**: 사용자가 목적지, 기간, 동행인, 테마, 예산 범위만 간단히 선택하면, 인공지능(AI)이 시간대별 동선이 최적화된 일정표와 예상 지출 비율, 짐 싸기 체크리스트를 30초 안에 원스톱으로 기획하여 제공합니다.

### 1.2 타겟 사용자 (Target Audience)
1. **바쁜 2030 직장인 및 학생**: 여행 갈 시간은 있지만 계획을 꼼꼼히 세울 여유가 부족한 사용자
2. **동행자와의 일정 조율이 필요한 여행자**: 연인, 친구, 가족의 취향을 모두 반영한 무난하고 만족도 높은 코스가 필요한 사용자
3. **가성비/가심비 여행객**: 본인이 설정한 예산 범위 안에서 가장 알차게 즐길 수 있는 추천 활동을 원하는 여행자

## 2. 페이지 및 섹션 구성 (Information Architecture)

트립스파크는 빠르고 직관적인 사용자 경험을 위해 **반응형 단일 페이지 애플리케이션(SPA) 구조**를 채택하였으며, 상단 네비게이션을 통해 각 섹션으로 부드럽게 스크롤 이동합니다.

```
[헤더] 로고 | 홈 | AI 플래너 | 추천 여행지 | 이용 방법 | FAQ | [보관함] | [🌙 다크모드]
  │
  ├── [Hero 섹션] 헤드라인 카피, 감성 소개, AI 플래너 바로가기 CTA, 신뢰 지표 뱃지
  │
  ├── [AI 플래너 섹션] (핵심 기능)
  │     ├── 입력 폼 (목적지, 기간, 동행자, 테마 태그, 예산, 특별 요청사항)
  │     ├── UX 피드백 (유효성 경고, 지연 안내 문구, 로딩 스피너 & 프로그레스)
  │     └── AI 생성 결과 (시간대별 타임라인, 예산 분석표, 체크리스트, 복사/저장/인쇄)
  │
  ├── [추천 여행지 갤러리 섹션] 제주, 강릉, 부산 등 대표 여행지 코스 프리셋 카드
  │
  ├── [이용 방법 섹션] 3단계 작동 프로세스 설명 (입력 → AI 분석 → 맞춤 일정 수령)
  │
  ├── [자주 묻는 질문(FAQ) 섹션] 인터랙티브 아코디언 (요금, AI 연동 원리, API 키 보안 등)
  │
  └── [푸터] 기술 스택 태그, GitHub 링크, 저작권 및 면책 조항
```

## 3. 핵심 AI 기능 상세 설계 (AI Feature Specification)

### 3.1 입력 사양 (Input Specification)
사용자가 폼을 통해 백엔드로 전달하는 JSON 페이로드 구조:
```json
{
  "destination": "강릉",
  "duration": "1박 2일",
  "travelers": "연인·커플과 함께",
  "theme": ["힐링/자연", "맛집 투어", "감성 카페"],
  "budget": "1인 15~25만원 (알뜰 실속형)",
  "notes": "바다가 보이는 오션뷰 카페 및 대중교통 이동 희망"
}
```

### 3.2 AI 프롬프트 엔지니어링 전략
- **역할 정의**: 여행 전문 컨시어지 AI 페르소나 부여
- **동선 최적화**: 이동 효율성을 고려하여 오전(도착/랜드마크) → 점심(로컬 시그니처) → 오후(감성 카페/체험) → 저녁(야경/디너) 흐름으로 구성
- **출력 정형화**: Markdown 펜스 없는 순수 JSON 응답을 강제하여 프론트엔드에서 안정적인 UI 렌더링 보장

## 4. 실패 및 예외 처리 매트릭스 (Error Handling Matrix)

과제 요구조건(빈 입력, API 오류, 지연/타임아웃 중 최소 1개 이상)을 넘어서 **4가지 상황 모두에 대한 철저한 UX 처리**를 구현했습니다.

| 예외 상황 | 발생 원인 | 감지 위치 | 사용자 안내 및 UX 처리 방식 |
| :--- | :--- | :--- | :--- |
| **1. 빈 입력 / 필수값 누락** | 목적지를 입력하지 않고 제출 버튼 클릭 | 클라이언트 (`ApiService.validateInputs`) | • 붉은색 경고 배너 표시: `"여행 목적지(도시 또는 지역)를 입력해주세요."`<br>• 입력 필드 포커스 및 강조 효과 |
| **2. 응답 지연 / 타임아웃** | 네트워크 환경 지연 또는 AI 모델 트래픽 폭주 | 프론트엔드 타이머 & `AbortController` (30초) | • 4초 경과 시: `"AI 연동으로 인해 약 5~15초 소요될 수 있습니다"` 안내 문구 노출<br>• 30초 초과 시: `AbortError` 감지 후 재시도 안내 배너 표시 |
| **3. API 오류 (4xx / 5xx)** | API 키 만료, 사용량 쿼터 초과(429), 모델 서버 장애 | 백엔드 (`api/generate.py`) & 프론트엔드 | • 429: `"AI 서비스 사용량 한도를 초과했습니다. 잠시 후 1~2분 뒤에 다시 시도해주세요."`<br>• 500: `"서버 처리 중 일시적 오류가 발생했습니다."` |
| **4. 키 미설정 / 데모 환경** | 배포 초기 환경 변수 미등록 또는 로컬 테스트 | 백엔드 / 프론트엔드 Fallback | • 서비스 중단 없이 스마트 시뮬레이션 데이터로 즉시 생성<br>• 상단 배너에 `"Vercel 환경 변수 등록 시 실시간 AI로 연동됩니다"` 안내 표시 |

## 5. 기술 아키텍처 및 데이터 흐름 (System Architecture)

```
[사용자 브라우저] (Vanilla HTML / CSS / JS)
       │
       │  1. 여행 조건 입력 및 [생성] 클릭
       │  2. 클라이언트 사전 검증 (빈값 체크)
       ▼
   [fetch POST /api/generate]
       │
       │  3. Vercel Serverless Function (Python 3.9+)
       ▼
[api/generate.py: handler]
       │
       ├── 환경 변수 확인 (OPENAI_API_KEY or GEMINI_API_KEY)
       │     │
       │     ├─ [키 존재 시] ──▶ OpenAI / Gemini REST API 호출 ──▶ JSON 응답 파싱
       │     │
       │     └─ [키 부재 시] ──▶ 지능형 스마트 시뮬레이션 모드 가동
       │
       ▼  4. HTTP 200 JSON 반환 (실패 시 400/500 에러 메시지 반환)
[사용자 브라우저 UI]
       │
       ├─ 시간대별 타임라인 카드 렌더링
       ├─ 예산 지출 분석 및 체크리스트 UI 렌더링
       └─ LocalStorage에 최근 플랜 저장 지원
```

## 6. 보너스 구현 항목 (UX 및 편의성 고도화)

1. **완벽한 다크/라이트 모드 지원**:
   - `prefers-color-scheme` 시스템 설정 자동 인식
   - 원클릭 전환 버튼 제공 및 `localStorage`에 테마 설정 영구 보존
2. **내 보관함 기능 (LocalStorage 기반 최근 플랜 관리)**:
   - 생성된 마음에 드는 일정을 원클릭으로 브라우저에 저장
   - 상단 헤더의 보관함 폴더 아이콘을 통해 저장된 플랜 목록 확인 및 즉시 재열람/삭제 가능
3. **원클릭 공유 및 인쇄 지원**:
   - 메신저나 메모장에 바로 붙여넣을 수 있는 [전체 일정 클립보드 복사]
   - 종이 출력 및 PDF 저장이 가능한 `@media print` 스타일 시트 최적화
