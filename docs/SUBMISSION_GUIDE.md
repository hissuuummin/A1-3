# 📸 과제 제출 증빙 자료 가이드 (Submission Guide)

본 문서는 **미션 최종 제출 패키지 5종** 중 **증빙 자료(스크린샷 및 AI 코딩 대화 로그)** 준비를 돕기 위한 상세 가이드입니다.

---

## 1. 제출 패키지 5종 점검 체크리스트

- [ ] **1. 배포된 웹 서비스 (Vercel URL)**: Vercel 배포 후 생성된 공개 URL
- [ ] **2. GitHub 저장소**: 프론트(`index.html`, `css/`, `js/`)와 백엔드(`api/`)가 구분된 저장소 링크
- [ ] **3. README.md**: 서비스 소개, 기술 스택, 실행/배포 방법, 환경 변수 설정법 완료
- [ ] **4. 서비스 기획서**: [`docs/SERVICE_PLAN.md`](SERVICE_PLAN.md) 작성 완료
- [ ] **5. 증빙 자료 세트**: 스크린샷 1세트 + AI 코딩 도구 대화 로그 1세트 (아래 안내 참조)

---

## 2. 필수 스크린샷 1세트 가이드

아래 3가지 필수 스크린샷을 캡처하여 저장소 또는 제출 폼에 첨부합니다.

### 📷 스크린샷 1: 데스크톱 메인 화면 (Desktop View)
- **촬영 위치**: 웹 브라우저 전체 창 (1920x1080 또는 1440x900 해상도)
- **포함 요소**:
  - 상단 네비게이션 바 (브랜드 로고, 메뉴 링크, 다크모드 토글, 보관함 아이콘)
  - Hero 섹션 (메인 타이틀, 통계 지표 뱃지, CTA 버튼)
  - AI 플래너 입력 폼 영역 상단

### 📷 스크린샷 2: 모바일 반응형 화면 (Mobile Responsive View)
- **촬영 위치**: 브라우저 개발자 도구(F12) → 디바이스 툴바(Ctrl+Shift+M) → iPhone 12/14 또는 Galaxy S20 모드 (가로 375px~390px)
- **포함 요소**:
  - 모바일 헤더 (햄버거 메뉴 버튼 및 아이콘)
  - 모바일 해상도에 맞게 1열로 자연스럽게 정렬된 폼 요소
  - 레이아웃 깨짐 없이 카드와 버튼이 알맞게 배치된 모습

### 📷 스크린샷 3: AI 기능 동작 및 결과 화면 (AI Feature Execution View)
- **촬영 위치**: AI 플래너 섹션에서 조건 입력 후 결과가 렌더링된 화면
- **포함 요소**:
  - 목적지(예: 강릉 또는 제주도), 기간, 동행자 태그
  - AI가 생성한 **시간대별 타임라인 카드 (오전/점심/오후/저녁)**
  - **예상 지출 분석 카드** 및 **준비물 체크리스트**
  - *(추가 권장)* 목적지를 비우고 제출했을 때 나타나는 **"필수 입력값 누락" 붉은색 경고 배너** 캡처

## 3. AI 코딩 도구 사용 과정 증빙 (대화 로그 템플릿)

AI 코딩 도구를 통해 문제를 정의하고 코드를 생성·수정해 나간 과정을 기록합니다. (아래 템플릿을 복사하여 제출에 활용할 수 있습니다.)

### [AI 코딩 대화 기록 요약]

- **사용 도구**: Antigravity (Advanced Agentic AI Assistant)
- **프로젝트 주제**: AI 기반 맞춤 여행 일정 & 경비 플래너 (TripSpark)

#### 대화 세션 1: 기획 및 아키텍처 설계
- **사용자 요청**: "바닐라 프론트엔드와 Vercel Serverless Functions(Python)을 사용하여 AI 웹 서비스를 만들려고 합니다. 바로 구현하지 말고 기획서부터 작성해주세요."
- **AI 제안 내용**:
  - 기존 예시를 탈피한 독창적 서비스 "트립스파크(TripSpark)" 기획
  - 단일 페이지 애플리케이션(SPA) 섹션 구성 (Hero, AI 플래너, 추천 코스, 가이드, FAQ)
  - Python Serverless Handler 및 에러 핸들링 4종 매트릭스 수립

#### 대화 세션 2: 프론트엔드 및 백엔드 구현
- **주요 작업 내용**:
  - `api/generate.py`: `BaseHTTPRequestHandler` 기반 경량 서버리스 함수 작성, OpenAI/Gemini 호출 및 안전한 스마트 시뮬레이션 모드 구현
  - `index.html` & `css/style.css`: 시맨틱 마크업, 반응형 Flexbox/Grid 레이아웃, 모바일 미디어 쿼리 구축
  - `css/dark-mode.css`: 다크 테마 변수 및 고대비 색상 설계
  - `js/api.js` & `js/app.js`: 필수값 검증, 타임아웃(30초) AbortController, 단계별 로딩 인디케이터, LocalStorage 보관함 구현

#### 대화 세션 3: 오류 원인 파악 및 트러블슈팅
- **발생 오류**: 로컬 정적 서버 실행 시 `/api/generate` 엔드포인트 연결 불가 (HTTP 404/Failed to fetch) 가능성
- **해결 방안**:
  - 순수 파이썬 내장 라이브러리만으로 정적 파일 서빙과 `/api/generate` 라우팅을 동시에 처리하는 `dev_server.py`를 제작하여 로컬에서도 Vercel 환경과 동일하게 원클릭 테스트 가능하도록 개선
  - 프론트엔드 `api.js`에 네트워크 단절 시에도 사용자 경험이 멈추지 않는 스마트 Fallback 처리 로직 보강
